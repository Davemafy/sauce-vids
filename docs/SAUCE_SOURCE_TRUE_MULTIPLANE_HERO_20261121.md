# Sauce — synchronized multi-plane hero cinema (November 21, 2026)

**Status:** Implemented as opt-in film-plan engine capability, source verified with actual public website Chromium capture, two independent original UI elements, native 60fps render, desktop/mobile playback, strict regression. **Creative quality is still REJECTED; NOT deployed into production URL-to-video or approved reference training/gold.**

## Why this experiment

The previous single real DOM layer could lift one card using a Chromium screenshot where that card was temporarily hidden. External Raycast/Jitter references (private research clips, copyrighted; no copy/admission as gold) use multiple independently staged interface elements and scene hierarchy: genuine foreground holds position while context can recede. A 2.5D camera on the whole browser screenshot alone cannot execute that editorial grammar.

Added a generic *2–3 real component group* to the established Sauce source-true compositor. Nothing is inpainted. All UI text, charts, border colors and states originate in actual same-source-time Chromium pixels. Source is a real website, not a reconstructed fake interface.

## Capture, contract, compositor

- Existing scripts/verified_dom_pair_capture.py now discovers up to three unique, visible, disjoint, opaque semantic UI elements from measured real DOM result rectangles. It captures one visible browser PNG, then hides exactly those genuine elements in that same Chromium virtual-clock instant, captures the actual clean page and restores all CSS (finally). Capturing multiple together is not the same as combining independent old single-card backgrounds; the clean plate has **all** selected native DOM surfaces hidden at once.
- Per-frame original video plus synchronized clean plate, identical native 60fps/resolution/frame count/duration. Live DOM source rects are browser measured; original source and clean video are SHA256 bound; provenance, strict off-region changed-pixel fraction <=0.00008, minimum inside each element, true original source/clean verified decoder frames all gate admission. Element source rect must belong to the proven observed result. All card IDs must be selected, never an imaginary third.
- New scripts/live_dom_multi_plane.py composes real visible or inactive cards onto the clean real page; original source pixels remain intact and per-card independently timed lift / lateral drift / scale / stage-only shadow. New optional normalized heroCenter [0.14..0.86] anchors genuine foreground UI screen position while the main real browser source camera recedes. For this case hero scale can reach 1.55; the original single-layer / nonhero scale max remains 1.18. After the effect, the genuine card returns to original source position.
- Source-relative actual luminance material gate rejects a pale source UI on similarly pale stage, without hardcoding product brand/color or swapping a model's chosen background. Real source-based projected hero geometry checked at *every actual source frame*: refuse if visible hero subject clipped or source cards obscure each other too much.
- New film JSON domPlanes[] (2 or 3) is mutually exclusive with old single domPlane and frozen isolation; requires existing authentic fullscreen StudioStage. Previous existing studio, glass loupe, pointer, Foley, source-hash rules remain.
- scripts/film_director_capabilities.py offers actualCapture.verifiedLiveDomPlaneGroup to Gemini **only** if real source+plate hash/geometry/pixel validator passes. It describes individually selectable source-true hero centers and original source-frame cut candidate evidence. Gemini is not permitted to synthesize cards/background/source.
- scripts/studio_plan_bounded_repair.py adds audited compatibility corrections, never overwriting original JSON or source events: snap nearest native frame, minor original-frame start corrections when result is proven by pixels, bounded model peak time <=0.2s advance to preserve required 0.9s return, and no-op window/default-center repairs. Strict original renderer validation still runs; no automatic creative approval.
