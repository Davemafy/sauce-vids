Requires a read-only Stagehand observation receipt, uniquely matched independently inspected Sauce control ID, and a fresh real Playwright preflight with `visible_outcome_candidate`. For a genuine compact outcome it creates a bounded wide → source action → *post-confirmed* physical dolly into the measured result → legible result hold → wide release. Its camera uses existing `reference-spring` and **only recorded pointer samples**. A second preflight samples every 60fps keyframe to reject unfilled browser shell regions. Whole-screen theme changes remain overviews, not fictitious detail regions. All existing renderer clipping and camera-speed admission rules apply.
- `scripts/stagehand_phase2_pipeline.py`: experimental opt-in coordinator for Sauce inspector → read-only Stagehand SDK observe → independently verified native60 capture → strict `verified_capture_receipt_adapter` → Phase 2 camera plan and validator → original encoded renderer → encoded quality supervisor. Fail-closed, bounded output, no overwrites, no author approval. It is **not deployed or enabled** as a public Studio endpoint. Tests cover schema, URL, no key, and preservation.
- `tests/test_stagehand_native_bridge.py` and `tests/test_stagehand_phase2_pipeline.py` cover 12 new native bridge/director/orchestration cases, including forged source refusals, untrusted selectors, secure redirects, true geometry and causal timing.

Pass the venv launcher path unchanged or use `.absolute()` instead of `.resolve()`. Preserve failed experiments for regression rather than inventing success.
