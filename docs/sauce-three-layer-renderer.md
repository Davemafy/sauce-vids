# Sauce — three-layer film renderer

The output is the product. These are **opt-in film-engine features**, not a new editor UI. The canonical pipeline remains SHA-verified Sauce session → screenshot-derived gaze evidence → TypeScript FramePlan + FoleyPlan → 1920×1080 OpenCV cinematic stage → 60fps WebGL2 shader → 48kHz Foley mux → MP4. Legacy recordings and no-preset output retain their existing behavior.

## 1. Refractive optics and real Foley light

`assets/shaders/optics-webgl2.html` contains a real WebGL2 GLSL ES 3.00 fragment shader. For `3d-launch` and `hyper-cut`, the final full-resolution screen texture supplies planar screen-space floor reflections; a constrained transparent-glass *edge* shader supplies small refractive and RGB dispersion offsets. Interior website text is left readable. Surface caustics are masked to the floor and gated by two uniforms, `clickEnergy` and `glassEnergy`.

The uniforms are generated by `foley_mixer.foley_shader_envelopes` from the same NumPy/SciPy sample assets and `outputSample` positions as the 48kHz WAV mix. At exactly 60fps, frame *i* owns samples `[i×800,(i+1)×800)`; no independent audio animation clock, network request, live microphone or random oscillator is permitted. Disabled/muted Foley produces zero audio-driven light. Shader grain is seeded by the output frame index, making seeking and rerendering deterministic. SwiftShader is supported on a CPU-only Vultr VM. The WebGL effect is a screen-space approximation, **not ray-traced 3D or a depth-buffer reflection**.

## 2. Provenance-required Git diff reveal

`feature-commit` is an optional `sauce.session.v1` event carrying an allowlisted commit hash, repository-relative path, title, and 1–16 bounded lines from a localized Git hunk. The session schema version remains v1 for backward compatibility. Every present commit event is validated before replay; omitted evidence produces no Git effect. The director ranks a validated commit as a feature moment, triggers a bounded spring camera micro-pivot, and schedules the `diffId`/`diffProgress` output-frame fields. `code_diff_reveal.py` transforms the **window and its actual pointer together** into a peeking browser card; a syntax-colored panel containing only recorded Git lines occupies the revealed stage space. This avoids inventing product source code.

After authorized capture, to add a *real* repo commit at an observed absolute session timestamp:

```bash
PYTHONPATH=scripts python scripts/git_evidence.py \
  --session /path/to/private/session.json \
  --repo /path/to/checked-out-repo \
  --commit <full-git-sha> --at-ms <capture-timestamp-ms>
```

The command reads Git metadata and patch text without executing repository code, checks the session's screenshot hashes, rejects recognizable private material, and writes only the bounded hunk into the private trace. The operator must ensure the commit pertains to the filmed product; the renderer cannot establish that relationship automatically. Do not annotate a recording with an unrelated repository.

## 3. Visual-saliency camera and timewarp

For versioned presets, `spatial_parallax.evidence_attention_events` reads existing SHA-verified PNG states, computes grayscale change, Sobel contrast, and dense Farneback optical flow at 256×144 resolution, and emits bounded `(x,y,score,flow)` records at source session timestamps. It sends no screenshot pixels to TypeScript. `timeWarp.ts` protects short windows around strong meaningful change and exports grounded gaze targets; `cameraRig.ts` spring-damps small focus/scale adjustments while action boxes override mere saliency. A screenshot without meaningful visual change yields no target. Both attention and commit moments use the **same monotonic source-to-output mapping** as existing clicks and Foley.

The outputs are heuristics, not claims of actual human eye tracking. Future attention models can replace proposal scoring without changing the frame-clock contract.

## Verification and limits

- The canonical frame loop remains sequential at 1920×1080 and 60fps. Optical-flow evidence is computed before playback, never from nondeterministic wall-clock screen captures.
- The Foley mix contains exactly 800 samples per output frame at 48kHz; AAC muxing may show submillisecond metadata rounding even when sample positions are aligned. Test content sync using `outputSample`, not AAC frame packet count.
- `python -m unittest discover -s tests -q` covers base contracts (render extras skipped when unavailable).
- `npm --prefix scripts/studio-motion test` covers deterministic plans, commit privacy, gaze and fixed-rate frame mapping.
- `SAUCE_BROWSER_TEST=1 python -m pytest tests/phase2 tests/phase3 -q` runs the existing integration suites; `apps/web` unit/typecheck suites remain unchanged.
- The verified initial film test was a private authorized Brimble trace and contains **no Git event**; the Git reveal was separately tested using an actual repository commit. No fabricated code diff was inserted into the Brimble film.
