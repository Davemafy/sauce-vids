# Sauce — watching, criticizing and recutting the real film (2026-11-21)

**Status:** Completed private, source-true Refit prompt-feedback experiment. Improved second recut; **commercial creative acceptance FAIL**. No release, production integration, new VM, or user-published MP4. Existing GitHub `main` and permanent Vultr worker only. Do not mistake an AI's “worth publishing” judgment for film approval.

## Motivation and method

Owner insight: Sauce's initial natural-language founder brief gave Gemini a stronger Refit story than a rigid JSON-director prompt. The crucial untested step was: **give Gemini the actual finished MP4; have it criticize the video; feed critique and hard renderer constraints into another request; rerender; independently inspect frames and playback; repeat.** We deliberately kept the **same Gemini 3.1 Flash-Lite model** rather than changing providers. The task was to test whether the missing quality could be reached through prompting, not to replace previously functioning capture/render systems.

Research harness: `scripts/experiment_film_feedback.py` (opt-in; Refit-calibrated creative prompts, not generic production URL direction). It sends an explicitly bounded **actual H.264 MP4** to Gemini as `inline_data` `video/mp4`; the model's returned time-specific critique and revised camera JSON are kept private. The source video SHA, event-manifest SHA, audio asset bytes, original source image and source-timed events **cannot be changed by model-produced camera JSON**. Engine `scripts/render_event_video.py --validate-only` rejects invalid anchors, speed, anticipatory zooms, clipped source evidence and mismatched hashes. The harness supports a maximum of two bounded corrective requests; it never clicks a browser action or regenerates UI. It resolves a missing immutable schema field or recognized camera-only array envelope by taking locked values from the verified base plan; it **does not** relax evidence or render restrictions. Model comparisons may contain hallucinated judgments and never grant human approval.

## Conclusion / next action

**Prompt feedback is effective but bounded.** It discovered a dead hold in actual pixels, altered the camera direction, rejected hallucinated JSON through the real deterministic compositor and recommended a legitimately shorter cut with better spoken truth. This worked with the **same lightweight Gemini model**. Yet neither better prompting nor a model switch can fabricate more real action than the input recording contains. The highest-leverage next experiment is a stronger **source-true, owner-authorized click → verified product state change → visually dominant payoff**, captured with readable source labels; then give Gemini that actual film for the same constrained critique/revision loop. Avoid an unbounded loop of attractive but empty camera pans over a single static metrics table. No production URL queue change until actual source film meets human creative acceptance.
