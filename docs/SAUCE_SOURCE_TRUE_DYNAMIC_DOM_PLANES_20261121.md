## Source problem and generic technique

Sauce had perspective camera motion over one whole video texture, frozen UI isolation and a Brimble-specific modal-free background. None offered independent, changing DOM-derived elements on top of genuinely different live browser pixels. Real references like Raycast 2026 deploy moving interface components and optical focus with their own spatial hierarchy, not just perspective over one miniature webpage.

New script scripts/verified_dom_pair_capture.py (the DOM-discovery and capture adapter):
- Discover one unique visible, opaque, non-sensitive semantic element near real verified result geometry; measured source CSS bounding box, opacity, CSS corner radius. Must be real DOM on the authorized browser page. No hardcoded site selector needed in the discovery function.
- Capture visible source PNG, temporarily set its actual DOM element CSS visibility hidden, capture hidden plate PNG with *same Chromium virtual clock and page*, restore previous CSS in finally. Refuse layout shifts, nonopaque surfaces, nonmatching outside-rectangle pixels or nonexistent element.
- Advance Chromium virtual clock 40ms/frame for 25fps independent of screenshot-wall-time. Convert each same-clock source frame and hidden plate frame into two matching source videos. Strict 64-character hashes and source geometry retained only in private sidecar.
- The private tweakcn research capture shows ~0.14s real elapsed to capture a 40ms visual frame; synchronization was supplied by Chromium's virtual clock, not inferred from wall clock. Production latency is not yet validated.

New script scripts/live_dom_depth_plane.py plus opt-in film JSON domPlane key and existing studioStage integration:
- Only film-plane IDs actually included in current capture manifest and checked against both real video hashes are selectable. Video decoder verifies matching native fps, duration, frame count and resolution.
- Same native indexed source frame N and clean-plate frame N feed the compositor; outside the true element rectangle differences above 12 pixel-intensity must be under 0.008%; inside must have identifiable real product pixels. An element must also overlap its verified real outcome geometry by at least 60% and have opaque CSS surface with a supported genuine source radius.
- The real source component texture projects independently from its native source rectangle using same world perspective; scale max1.18, lift max160px, genuine card typography and plot remain exactly the captured source pixels. Shadow is stage-only. Its underlay comes from real browser hidden-element frame and the element settles back into its exact original position. A single genuine pointer drawn after all layers.
- No new external network service, inpainting, imagined UI, invented cursor path, altered product state, DOM content mutation or synthetic result. Invalid video, provenance, timing, material, viewport or effect fails closed; normal unchanged render path unaffected.
