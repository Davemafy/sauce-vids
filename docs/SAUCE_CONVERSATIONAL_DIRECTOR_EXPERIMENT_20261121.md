## Actual implementation on isolated persistent Vultr workspace
- `scripts/conversation_director_experiment.py` — three real Gemini REST requests, ordinary founder conversation first; second independent skeptical creative critic; third strict JSON compiler. The compiler sees observed page/control IDs and same-origin link destinations, never raw executable CSS/JS selectors. Fail-closed validation requires verbatim webpage evidence, reachable page transitions, correct starting-page hook, allowed action class, distinguished historical/site claim. No image-generation of source UI. The second critic may be wrong and is treated as untrusted speculation, not execution authorization.
- `scripts/compile_conversation_capture.py` — independently resolves observed read-only links against a **fresh** DOM; checks unique live element, exact href, safe origin and actual navigation/scroll destination, compiles into Sauce’s existing `session_capture.py` workflow. No model-generated selector is executed. Costly/destructive/nondeterministic/unknown buttons remain merely **proposed**, including Refit's “Run refund agent”; this experiment performed **zero** live refund inference, forms, submissions, purchases or external communications. The compiler refuses unsupported live operations and keeps page/text claims source-marked.
- `scripts/session_replay.py --raw-replay --cursorless-source`: narrow **opt-in** native fullscreen DPR2 browser pixel output without legacy tiny-window studio stage or pre-baked pointer. Works with existing separately validated JSON film plan's source-clock pointer, event bounds and audio. Rejects incompatible presentation modes; normal Sauce film defaults remain unchanged.

## Acceptance and boundaries
- This is an **experimental opt-in CLI**. It is not automatically wired into the production URL queue or self-serve Studio, and there is no autonomous approval or public publication.
- A three-model conversation can invent compelling but unsupported product behavior. Independent deterministic grounding and route verification catch many cases, but **a quote on a marketing page does not independently prove the claim**. Neither model prompts nor valid JSON alone authorize risky browser actions.
- The Refit test is only one owner-controlled URL; Brimble is a meaningful held-out **failure**. No claims of generalizable zero-touch premium output.
- Screenshots, HAR, model generated content, raw footage and MP4 remain private on the **existing Vultr worker**; no new service, VM, public artifact, billing account, purchase, branch, or production change.
- Accept: end-to-end technical interoperability and improved source composition; reject: premium film / generalization / held-out Brimble real-proofs.
