# Mint Cursors — source artwork provenance

**Creator / original distributor:** Colorosse — Mint Cursors, a CC0 1.0 2D UI cursor pack.

**Source:** https://www.colorosse.com/assets/2d/ui/mint-cursors
**Verified distribution:** https://cdn.colorosse.com/downloads/mint-cursors/mint-cursors.zip
**Retrieved:** 2026-11-22.

The `arrow.svg`, `hand.svg` and `text.svg` files here are the source SVGs
from the original archive, copied verbatim. The original site identifies the
pack as **CC0-1.0**, permitting unrestricted commercial reuse, modification,
and redistribution. See https://creativecommons.org/publicdomain/zero/1.0/

Sauce uses the original arrow geometry and native `hotspot 0,0` metadata.
Its render-only, high-contrast mode recolors the outer `#66757f` stroke to
`#f5f7fb`; it does not distort the path, invent pointer movements, or override
application pixels. The complete original cursor archive remains available
from the credited source; no changes to the user’s browser cursor are made.

Cursor packs with other licenses (Bibata: GPLv3; Phinger: CC BY-SA 4.0) were
consulted solely as visual references and are **not redistributed** here.
